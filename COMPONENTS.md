# Blackout Syndicate 2.0 — Builder's Guide

The site is plain static HTML generated by `node build.mjs` (zero dependencies) into `docs/`.
Every page is one module in `src/pages/*.mjs`. The layout (`src/layout.mjs`) adds the head, top bar,
clearance HUD, "next file" teaser, footer, drawer and toasts. You only write the page's `<main>` content.

## Page module shape

```js
// src/pages/31-faq.mjs
import { BIZ } from '../data/business.mjs';
export default {
  path: 'faq.html',            // output path (subfolders allowed)
  file: 'File 14',             // set => this page is a "file" that earns clearance (visit + read)
  order: 31,                   // reading order in the clearance drawer
  navTitle: 'FAQ',             // short name used in drawer and next-file teaser
  section: 'faq',              // highlights the nav item: packages | how | work | about | faq | contact
  title: 'FAQ',                // <title> becomes "FAQ · Blackout Syndicate"
  description: '…',            // meta description, 140–160 chars, plain and specific
  teaser: '…',                 // one line shown (half redacted) on the previous page's "Next file" card
  next: 'about.html',          // which page the "Next file" card at the bottom points to
  css: `…`,                    // optional page-only CSS (inlined in <head>)
  js: `…`,                     // optional page-only script (runs after site.js; window.BS is ready)
  jsonld: (ctx, config) => ({…}), // optional structured data
  noindex: true,               // optional
  body: (c) => `…html…`,       // the page content; `c` is the helper context below
};
```

Pages without `file` (thank-you, vault, privacy, terms, 404) give no clearance for visiting.

## Helper context `c`

| Helper | What it does |
|---|---|
| `c.link('contact.html')` | Relative URL that works from any folder depth. **Always use it for internal links.** |
| `c.btn(text, href, variant)` | Button link. Variants: `''` gold, `'ghost'`, `'lg'`, `'sm'`, `'paper'` (for paper bands), combine with spaces: `'ghost lg'`. |
| `c.arrow` | Inline arrow SVG for buttons/links. |
| `c.classified({ id, level, title, body, bypass })` | Redacted paper dossier that opens at clearance `level` (1–5). `body` is HTML with `<p>`, `<ul><li>`, `<ol><li>`. Unique `id`. `bypass: true` adds "Break the seal anyway". |
| `c.mark('m1')` | One of the 3 hidden marks (+25 clearance). Ids `m1` (about), `m2` (how-it-works), `m3` (faq). Hide it somewhere discoverable but not obvious: inside a heading, next to a rule, at the end of a paragraph. |
| `c.offerCard(offer)` | The package "file" card. |
| `c.crumbs([{t,p},…,{t}])` | Breadcrumbs. Last item has no `p`. |
| `c.contactLines()` | Big phone number + email with copy buttons. |
| `c.socialRow()` | Social links with icons. |
| `c.icon('x')` | Brand icon SVG: x, tiktok, instagram, facebook, youtube, discord. |
| `c.config` | The merged build config (`src/config.mjs` plus any `BS_CONFIG_OVERRIDE`). Read switches such as `c.config.showPayLinks` from here, never by importing `config.mjs`. |
| `c.BIZ`, `c.SOCIALS`, `c.LEVELS`, `c.POLICY` (refund/billing wording: use it verbatim), `c.PLATFORMS`, `c.REEL`, `c.OFFERS`, `c.BOOSTS`, `c.PLANS`, `c.ADDONS`, `c.SERVICES`, `c.offerPath(o)` | Data. Never hard-code a price: read it from the offer. |

## CSS components (in `src/assets/css/site.css`)

Tokens: `--void --coal --vault --smoke --ash --paper --ink --ink-mute --gold --gold-hi --brass --signal`;
fonts `--f-display` (Big Shoulders Display, uppercase headlines), `--f-body` (Archivo),
`--f-serif` (Bodoni Moda italic, the "whisper" accent), `--f-type` (Courier Prime, dossier labels).
Never introduce new colors or fonts. Use the tokens.

**Structure**
- `<section class="band">` → `<div class="wrap">`. Variants: `band--coal` (raised dark), `band--paper` (light dossier page, use 1 per page at most), `band--gold` (loud closing CTA, at most 1 per page), `band--tight`, `band--flush-top`.
- Inner page header: `<header class="pagehead"><div class="wrap pagehead__in">crumbs, .label, h1.h1, p.lede, .ctas</div></header>`
- `.band__head` (label + h2 + p) and `.band__head--row` (head left, link right).
- Grids: `.grid.grid--2|3|4`, `.split`, `.split--wide`. `.wrap--narrow` for reading width.

**Type**
- `.label` (typed uppercase eyebrow; `.label--dim`, `.label--red`), `.h1`, `.h2`, `.h3`, `.lede`, `.muted`, `.small`.
- Whisper accent inside a headline: `<h2 class="h2">Asked <span class="whisper">and answered.</span></h2>`. Use once per heading, not on every heading.
- `.prose` for long text (handles p, h2, h3, ul, ol, a, strong).

**Pieces**
- `.steps` ordered list (`<ol class="steps" style="--n:4"><li><h3>…</h3><p>…</p></li></ol>`). Only for a real sequence.
- `.ticks` / `.ticks--no` lists. `.ledger` (`<dl class="ledger"><div><dt>…</dt><dd>…</dd></div></dl>`).
- `.panel` (raised box), `.note` (dashed callout), `.badge.badge--red|gold`, `.stamp` / `.stamp--gold` (rotated rubber stamp).
- `.qa` FAQ: `<details class="qa"><summary>Question</summary><div><p>Answer</p></div></details>`.
- `.textlink` for "Read more →" style links (`<a class="textlink" href="…">Text ${c.arrow}</a>`).
- Forms: `.form`, `.form__row`, `.field` (label + input/select/textarea + `<p class="field__err" data-err-for="name"></p>`), `.chips/.chip`, `.form__alert`, `.hp` honeypot.
- Focus rings switch to ink on `band--paper` and `.classified`, and to void on `band--gold`. Anything else on a light or gold surface needs its own `:focus-visible { outline-color: … }`.
- A locked `.classified` body is clipped to about 11em and fades out, so long files don't become screens of black bars. Links inside a locked body leave the tab order.
- Add `class="rv"` to section-level blocks for a reveal on scroll (only fires for things below the fold). Optional `style="--d:.1s"` delay.
- `data-spot` on any element makes a gold searchlight follow the pointer (`--x/--y` set in px). Use for one hero-ish moment per page at most.

## Engine API (window.BS, available in page `js`)

- `BS.award(kind, id, amount, label)` — kind is `seen|read|mark|quiz|lead|blackout`. Use `BS.award('quiz', '', BS.XP.quiz, 'Package match found')`.
- `BS.track(name, params)` — X pixel event by config key (`lead`, `formSubmit`, `packageView`, `contactView`).
- `BS.toast(main, sub, big, tone, href, note)`, `BS.state()`, `BS.level()`, `BS.open()` (opens clearance drawer), `BS.reduce` (reduced motion). Toasts never block taps; a toast with `href` is a link (`'#clearance'` opens the drawer).
- Clearance is re-read from storage before every write, so several open tabs never wipe each other. Always change state through `BS.award()`, never by writing to `BS.state()`.
- Lead form: `<form class="form" data-lead novalidate>` with fields named `name` (required), `business`, `email` (required, type=email), `phone`, `interest` (select; each option `value="spark"` and `data-slug="spark"`), `platform`, `message`, plus honeypot `<input name="_honey" class="hp" tabindex="-1" autocomplete="off">`, `<div class="form__alert" data-form-alert hidden></div>`, and `<button class="btn btn--lg" type="submit">`. The engine handles validation, sending, pixel events and redirect to thank-you.html. `?pkg=slug` preselects.
- Thank-you: elements `[data-lead-name]`, `[data-lead-interest]`, `[data-lead-preview]` (hidden unless preview) are filled automatically.

## Voice (non-negotiable)

- Plain, short, direct. Talks like a straight-shooting local guy. "We" for the business, "I" only inside founder quotes.
- **No invented facts**: no testimonials, client names, case studies, stats, follower counts, ratings, years in business beyond "ten years building things with my hands", awards, guarantees of results, office address, hours. If it isn't in `src/data/*.mjs`, don't claim it.
- Results line (use where you sell promotion): "Results depend on your content, your audience and the platform. No set number of views, likes or followers is guaranteed."
- No em-dash asides, no "not X, but Y" framing, no "worth noting", no emoji, no exclamation spam.
- Prices only from `src/data/offers.mjs`.
- The syndicate/noir theme is flavor, not confusion: every heading must still say plainly what the section is about.
