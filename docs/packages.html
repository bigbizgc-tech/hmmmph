Four rules of thumb

How to choose

If the questions didn’t settle it, these will. They are the same rules we use when someone calls and asks which file to buy.

Take the 3 questions

  1. Never run an ad? Start small.

    Spark is the smallest real test: a 3-day run, and the 30-Day Post Kit comes with it. You find out what real reach feels like before you go bigger.

  2. Fix the page before you buy the traffic.

    If your bio doesn’t say what you do, where you are and what to do next, an ad just sends more people to a page that loses them. Profile Fix first.

  3. One date? Buy a boost. Every week? Get a plan.

    A boost is one push for one moment. If you keep buying them, stop. Surge keeps the push running every month and never restarts from zero.

  4. Pay for the help you’ll actually use.

    If you’ll post yourself, Surge is enough. If posting never happens, Overdrive. If you want the whole operation off your plate, Total Blackout.
